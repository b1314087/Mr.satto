# 実機での確認手順（パスキー）

機能スイッチをオンにして、本番（https://mrsatto.com）に反映したあとで行います。
**有料プランのテスト用アカウント**（管理画面で無料付与したアカウントでよい）でログインして確認します。
自動テストは仮想のパスキーで行ったので、**実機での登録・本人確認は、この手順でまだ一度も確かめていません**。
パスキーの登録・本人確認で、**メールの確認コードを求められることはありません**（どの端末でも）。

確認の順番：①iPhone（1台目）→ ②Mac（2台目）→ ③Android（3台目・上限の確認）→ ④Windows（解除して登録）

---

## ① iPhone（Appleのパスキー）— 1台目
**登録**
1. iPhoneのSafariで https://mrsatto.com を開き、テスト用アカウントでログインする。
2. 「アカウント」→「パスキーと登録端末を管理する」を開く（または、AIのツールで出る「パスキーを登録する」）。
3. 「パスキーを登録する」を押す → 「パスキーを保存しますか？」が出たら「続ける」→ Face ID。
4. 「パスキーを登録しました」と出て、「この端末の状態」が「ご利用中です」になる。

**正常と判断する条件**：登録端末が「1/2台」で「iPhone・Safari」に「この端末」の印。プレミアム限定のツール（PDF→Excel など）が開ける。

**本人確認（再ログインの確認）**
- Safariのタブをすべて閉じてから開き直し、「パスキーと登録端末」を開く → 「パスキーで本人確認する」→ Face ID → 「ご利用中です」に戻る。

## ② Mac（Appleのパスキー）— 2台目
1. MacのSafari（またはChrome）で同じアカウントにログインし、「パスキーと登録端末」を開く。状態は「この端末は、まだ登録されていません」。
2. 「パスキーで本人確認する」→ iCloudキーチェーンで同期されたパスキーが出る → Touch ID（またはiPhoneでQRコード）。
3. そのまま登録され、「別の端末での利用を終了し、この端末で利用を開始しました」と出る。

**正常と判断する条件**：登録端末が「2/2台」。iPhoneに戻って何か操作すると、1分以内に「別の端末で有料プランの利用が始まったため…」の案内が出て、プレミアム限定のツールが「本人確認が必要です」になる。

**端末の切り替え**：iPhoneで「パスキーで本人確認する」→ Face ID → iPhoneに戻る。Mac側に案内が出る。

## ③ Android（Googleのパスキー）— 3台目は登録できないことの確認
※Googleのパスキーは、Appleのパスキーとは同期されません。先に、Android（またはWindows）用のパスキーを追加します。
1. ②のMacで「パスキーを追加する」→ 画面の案内で「別の端末を使う」→ AndroidでQRコードを読み取り、Googleパスワードマネージャーに保存する（または、Androidで本人確認できる端末から追加）。
2. AndroidのChromeで同じアカウントにログイン →「パスキーで本人確認する」→ 指紋・画面ロック。
3. 「登録できる端末は最大2台です。新しい端末を登録するには、現在登録されている端末を1台解除してください。」と出る。

**正常と判断する条件**：登録端末は「2/2台」のまま。

## ④ Windows（Windows Hello）— 解除して登録
1. ③のAndroidの画面で、登録端末のどちらか（例：Mac）の「登録を解除」→「解除する」。
2. Androidが登録され、利用が始まる。
3. WindowsでもEdgeで同じ流れ（Windows Helloのパスキーを追加 → 本人確認 → 上限なら解除 → 登録）を試す。

**正常と判断する条件**：解除した端末では、プレミアム限定のツールが使えなくなる。登録端末は常に2台まで。

## うまくいかないときの確認事項
| 症状 | 確認すること |
|---|---|
| 「このページのアドレスでは、パスキーを使えません」 | アドレスが https://mrsatto.com か（www や vercel.app ではないか） |
| パスキーの画面が出ない・すぐ閉じる | OS・ブラウザが新しいか。iPhoneは「設定→パスワード」でiCloudキーチェーンがオンか。シークレットウィンドウではないか |
| 「本人確認の失敗が続いたため…」 | 15分待ってから再度 |
| ずっと「別の端末で利用中」 | もう一方の端末でログアウトするか、この端末で「パスキーで本人確認する」を押す（切り替わる） |

問題があったら、画面のスクリーンショット（パスワードが写らないように）を送ってください。
