# 外字・特殊文字チェック：形違いの字をチェックしてまとめてコピー 報告書

作成日：2026-11-01（利用者からの依頼「外字を複数コピーできるように、漢字にチェック欄をつけチェックを入れてコピーを押すとその漢字はコピー＆ペーストできるようにして欲しい」による。ファイル名は既存の報告書と重ならないよう stage31 とした）

## 最初に（結論）

- 「形の違う字」の一つ一つの字の下に、チェック欄を付けた。字（枠の中の字）を押しても、チェックが入る
- チェックを入れると、その字の枠が青くなり、画面の下に「選んだ字：髙𠆪（2字）［選んだ字をコピー］［選択を解除］」の欄が出る（下に固定で、一覧を下へ見ていっても押せる）
- 「選んだ字をコピー」で、チェックを入れた順に字をつなげてコピーする（区切りの文字は入れない）。押すと「コピーしました」に変わる
- 異体字セレクタ付きの字も選べ、セレクタごとコピーする
- 一つずつの「コピー」ボタンは、これまでどおり残した
- 新しく調べ直すと、選んだ字は消える
- commit・push・マージ・デプロイは行っていません
