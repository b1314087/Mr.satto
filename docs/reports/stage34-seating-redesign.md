# 座席表作成の作り直し 報告書

作成日：2026-11-01（利用者からの依頼「座席表生成ツールの改善」による。ファイル名は既存の報告書と重ならないよう stage34 とした）

## 最初に（結論）

- 座席表作成（`/tools/seating-chart`、URLは変えていない）を、次の流れに作り直した
  1. 用途を選ぶ（会議（対面）・会議（コの字）・グループワーク・授業・懇親会（円卓）・カスタム）
  2. 名前と役職を入れる（1行に1人、「,」やタブのあとが役職。Excel・CSVから読み込める）
  3. 入力した順番に、席番号1から自動で入る
  4. 画面の下に固定したプレビューで、ドラッグ、または2人を選んで［入れ替え］
  5. 画像（PNG・JPEG）・PDF・Excelを選んで書き出す
- 追加（利用者の了承による）：席に「来賓」「司会」などの札を付けられる。PDFの用紙（A4・B4・A3）を選べる
- 利用者の判断（質問への回答「どちらも消す」）で、ランダムな席順（再抽選）と、条件（同じテーブル・別のテーブル・席の固定）を外した
- 画面の文字は、見出し・項目名と、入れ替えの方法（「入れ替え：席をドラッグ、または2人を選んで［入れ替え］」）だけにした
- commit・push・マージ・デプロイは行っていません

## 2. 用途と、席の入れ方

| 用途 | 席の形 | 入れる順番 | 変えられる項目 |
|---|---|---|---|
| 会議（対面） | 長机の両側＋端の議長席 | 議長席が1番。そこから近い順に、奥側・手前側へ交互（役職の高い順に入力すると上座から並ぶ） | 片側の席数、議長席の有無 |
| 会議（コの字） | 正面＋左右、開いた側に「前（スクリーン）」 | 正面の真ん中から外へ、その後に左右へ交互 | 正面の席数、左右の席数 |
| グループワーク | 島（長机の両側） | 「島ごとに詰める」か「1人ずつ順に配る」 | 島の数、1島の席数、入れ方 |
| 授業 | 教室の机（2列ごとに通路）、前に「教卓」 | 「前から横に」か「前から縦に」 | 横の席数、前からの列数、入れ方 |
| 懇親会（円卓）（おすすめとして追加） | 丸テーブルのまわり | テーブルごとに12時の位置から時計回り | テーブルの数、1卓の席数 |
| カスタム | 格子。マスを押すと席と通路が切り替わる | 前から横に | 横の席数、前からの列数、通路 |

- 「人数に合わせる」（既定でオン）：人数が変わると、席の数（テーブル数・行数など）が自動で増減する。数を手で変えると自動はオフになる
- 席が足りないときは「席が◯席足りません（名前…）」と座れない人を出し、「人数に合わせる」のボタンで直せる
- 円卓の半径は、席どうしが重ならない大きさを計算して決める

## 3. 入れ替え

- ドラッグ：席を押したまま別の席へ動かして離すと入れ替わる（空席へも動かせる）。動かしている間は、重ねた先の席が緑に光る。マウスとタッチの両方で動く（Pointer Events）
- 2人を選んで入れ替え：席を押すと青く選ばれ、2つ選ぶと［入れ替え］が押せる。キーボードでも操作できる
- 「入力順に戻す」で、入力した順番の並びに戻る
- 入れ替えたあとに名前を足しても、入れ替えた人の席はそのまま。新しい人は空いている席へ入る

## 3-2. 席の札

- プレビューで席を選ぶ（1つでも2つでも）と、「札」の欄が出る。候補（来賓・主賓・司会・議長）を押すか、自由に書いて（10文字まで）「札を付ける」。「札を外す」で消す
- 札は人ではなく席に付く（人を入れ替えても、札は席に残る）。用途を変えると消える
- 画面・画像・PDFでは席の右上に黄色の札、Excelでは「札」の列に出る

## 4. 固定のプレビュー

- 画面の下に固定した枠（スクロールしても見える）に、座席表を縮小して表示する。「たたむ」で小さくできる
- 枠は画面の高さの約38％まで。上の入力欄が枠の裏に隠れないよう、入力欄へ移動するときは下に余白をとる

## 5. 書き出し

- 画像（PNG・JPEG）：画面と同じ配置を、2倍の解像度で描く（タイトル・席番号・名前・役職）
- PDF：A4・B4・A3から用紙を選べる（既定A4。横長の配置は横向き）。1ページに収める。文字のまま描くので、拡大しても粗くならず、文字を選べる（日本語フォントを埋め込み）
- Excel：席番号・名前・役職・場所（「議長席」「島2」「前から2列目・左から3番目」など）の一覧。席に入らなかった人は「（席なし）」
- 画像とPDFは、同じ描き方の関数（`paintChart`）から作るため、画面・画像・PDFの並びは一致する
- 名前はブラウザの中だけで扱い、外部へ送らない

## 8. 制約・今後の候補

- PDFは1ページに収めるため、人数がとても多い（数百人）とA3でも文字が小さくなる（その場合は画像の書き出しか、複数ページへの分割が候補）
- 島の席数を変えると、島の形（両側の席数）も自動で変わる。片側だけに座る島などの形は、カスタムで作る
- 名簿の並べ替え（役職順など）は今回入れていない
