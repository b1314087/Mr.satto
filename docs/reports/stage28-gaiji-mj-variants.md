# 外字・特殊文字チェック：戸籍・住民基本台帳などの字（MJ文字）も形違いとして出す 報告書

作成日：2026-11-01（利用者からの質問「もっとない？」と、依頼「戸籍で使う珍しい字が出た時はどのような字体で出せば出るかをわかりやすくして」による。ファイル名は既存の報告書と重ならないよう stage28 とした）

## 最初に（結論）

- 形違いの字に、戸籍・住民基本台帳・入管などで使われる字（文字情報基盤のMJ文字）を加えた
  - 使ったデータ：文字情報基盤「MJ縮退マップ」「MJ文字情報一覧表」（© IPA、CC BY-SA 2.1 JP）
  - 約8,400字について、約28,900の形違いの字（異体字セレクタ付きの字を含む）
- 例：
  - 高 → 髙・𠆪（戸籍統一文字）
  - 寝 → 寢・寑・㝲・𡨞・𡨦・𡫒・𡬓、寢の異体字セレクタ付きの字
  - 辺 → 邊・邉・𨘢 など、辺・邊・邉の異体字セレクタ付きの字（MJ番号つき）を合わせて40字ほど
- 異体字セレクタ付きの字（同じ文字コードのまま、形だけを変えた字）には、MJ番号（例：MJ025759）を付けた。対応した書体がないと元の字と同じ形に見えるため、MJ番号で本来の形を確かめられるようにした
- 戸籍の珍しい字が出たときは、どの書体なら出るかを案内する欄を出す（下の「書体の案内」）
- 一覧は約22万字と大きいため、最初に結果を出すときに読み込む（ページを開いたときは読み込まない）
- commit・push・マージ・デプロイは行っていません

## 2. 集め方

- MJ縮退マップは、MJ文字（戸籍統一文字・住基ネット統一文字・入管正字など約5.9万字）を、ふつうの字（縮退先）に結び付けた表
- 次の表を使った：JIS包摂規準・UCS統合規則、戸籍統一文字情報（親字・正字）、民一2842号通達（誤字俗字・正字一覧表）、民二5202号通知（正字・俗字等対照表）、法務省告示582号（入管の正字）
- 関係がゆるい「辞書類等による関連字」「読み字形による類推」は使わない
- 入力した字について、次をまとめて出す（同じ字は1回だけ）
  - 前回までの一覧（新字体・旧字体・異体字の公開データ）の形違い
  - その字を縮退先とする字、その字を形違いに持つ字
  - それらの字の形違い（2段目まで。例：辺 → 邉 → 邉の異体字セレクタ付きの字）
- 貼り付けたときの正規化（NFC）で別の字に変わる字（互換漢字の一部）は除いた
- データは `scripts/gaiji/generate-mj-variant-data.py` で作った（@mandel59/mojidata 1.9.3 の中のデータを使用。サイトの依存関係には入れていない）

### 書体の案内

- 形違いの字の中に、ふつうの書体では出ないことがある字があるとき、「□や？になる字、形が同じに見える字を、正しい形で出すには」の欄を出す
  - 無料の書体「IPAmj明朝」（戸籍統一文字・住基ネット統一文字の約5万8千字を収録）の配布元（文字情報技術促進協議会 https://moji.or.jp/mojikiban/font/ ）へのリンク
  - 入れ方（ZIPの中の ipamjm.ttf を、Macはダブルクリック→インストール、Windowsは右クリック→インストール）
  - Word・Excelでは、その字の書体を IPAmj明朝 にすること
- 字ごとに、次の目安を出す
  - 「書体によっては□」：Shift_JISにない字・補助面の字（ふつうの書体にないことがある）
  - 「IPAmj明朝で正しい形」：異体字セレクタ付きの字
  - Shift_JISにある字には、書体の注意を出さない
- 「IPAmj明朝で表示する」にチェックを入れると、形違いの字を IPAmj明朝 で表示する（その書体をパソコンに入れてある場合だけ効く。サイトから書体を読み込むことはしない）

## 6. 残っている制約

- 異体字セレクタ付きの字は、IPAmj明朝などの対応した書体がないと、元の字と同じ形に見える（MJ番号で確かめる）
- 会社や自治体が独自に作った外字（私用領域の文字）は、作った所ごとに違うため出せない
- 形違いの字が多い字（辺など）は、一覧が長くなる
- 補助面の珍しい字（𠆪 など）は、パソコンの書体にないと、四角などで表示される

## Claudeの意見

- 異体字セレクタ付きの字を、書体を入れていない人にも本当の形で見せるには、IPAmj明朝（約40MB）をサイトから読み込む必要があり、ページがかなり重くなるため入れていません。書体を入れてもらう案内と、MJ番号で確かめる形が現実的だと思います。
- Safari は、自分で入れた書体をページに使わせないことがあります。その場合は、コピーして Word などで確かめる案内にしています。
