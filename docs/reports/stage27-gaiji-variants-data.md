# 外字・特殊文字チェック：形の違う字（異体字）の一覧を約2,400字に広げる 報告書

作成日：2026-11-01（利用者からの質問「寝の外字とかは？」による。ファイル名は既存の報告書と重ならないよう stage27 とした）

## 最初に（結論）

- 前回（stage26）の形違いの字の一覧は、手で集めた約90組だけだったため、「寝」の旧字体「寢」などが出なかった
- 公開されている2つのデータ（どちらも MIT ライセンス）を合わせて、一覧を約1,100組・約2,400字に広げた
  - 寝→寢、学→學・斈 など、国→國・圀 など、体→體・躰 など、剣→劍・劔・釼 など
- 前回の手で集めた組（高・髙、吉・𠮷 など）も、そのまま含む
- 新しい部品（パッケージ）は使っていない。データだけを取り出して、ファイルに入れた
- commit・push・マージ・デプロイは行っていません

## 2. 使ったデータ

| データ | 中身 | ライセンス |
| --- | --- | --- |
| kyujitai 1.3.0（hakatashi） | 新字体と旧字体の対応 773組 | MIT |
| itaiji 1.2.0（Yuta Mizui） | 異体字と正字体の対応 1,404組（東京大学史料編纂所「異体字同定一覧」をもとにしたもの） | MIT |

- 2つを合わせ、つながる組は1つにまとめた（例：斉・斎・齋・齊・亝・斊）
- 貼り付けたときの文字の正規化（NFC）で別の字に変わる字と、漢字以外の字は除いた
- ライセンスの表示（著作権者・許諾の文）は、データのファイル `src/lib/gaiji/variant-data.ts` の先頭に入れた

## 4. 実行したテストと結果

外字・特殊文字チェックのテストすべて（`gaiji-checker.spec.ts`・`gaiji-detect.spec.ts`・`gaiji-variants.spec.ts`）：43件合格

追加・変更したテスト：

- 「寝屋川」と入力すると、寝の形違いとして寢（U+5BE2）が出る
- 一覧が2,000字以上あり、すべて漢字1文字で、正規化で変わらず、どの字にも形違いがある
- 崎は 埼・嵜・碕・﨑、辺は 邉・邊、斉には 齋 が含まれる
- 「高橋 太郎／山田 花子／高木」では、高・橋・郎（郞）・花（芲）の4文字が出る

型チェック（`tsc --noEmit`）・ESLint（変更したファイル）：エラー・警告なし。

## 5. 残っている制約

- 公開データにない字の形違いは出ない（必要な字は、手で集めた組に足せる）
- 中国の簡体字が含まれるまとまりがある（例：橋の形違いに「桥」）。名簿で使うことはまれだが、出どころのデータどおりに残した
- 崎の形違いに「埼」が出るなど、今は別の字として使われている字が出ることがある
- 独自の外字・異体字セレクタの字形は、前回と同じく出ない

- 簡体字（桥など）が紛らわしければ、日本の名簿で使わない字を外すこともできます。実際に使ってみて気になったら言ってください。
