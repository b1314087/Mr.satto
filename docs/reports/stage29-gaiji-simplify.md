# 外字・特殊文字チェック：書体の案内を一文に・ファイルを調べる機能を外す 報告書

作成日：2026-11-01（利用者からの依頼「ここの説明が長いし小さいから読む気失せます。できれば一文で見やすいフォントサイズ、気付きやすいようにしてください」「ドラックアンドドロップの機能なしでいいかも」による。ファイルの扱いは、質問への回答「ファイルを調べる機能ごとなくす」で決定。ファイル名は既存の報告書と重ならないよう stage29 とした）

## 最初に（結論）

- 戸籍の珍しい字の書体の案内を、一文にした
  - 「⚠ □になる字は、無料の書体「IPAmj明朝」をここから入れると正しく出ます。」（16pxの太字。左に橙色の線を付けて目立たせた）
  - 「ここから入れる」が配布元（https://moji.or.jp/mojikiban/font/ ）へのリンク
  - その下に「入れたあとは、ここにチェックするとIPAmj明朝で表示します」のチェック
  - 入れ方の手順・ラベルの説明・ブラウザの注意は消した
- ファイルを選んで調べる機能（ドラッグ＆ドロップの欄）を外した。貼り付けた文字だけを調べる
  - 「方法1：文字を貼り付ける」は「調べる文字を貼り付ける」に変えた
  - 他のツールから、このツールへファイルを送る受け渡しも外した
  - ツールの説明・使い方・よくある質問を、貼り付けだけの内容に直した（Word・Excel・PDFの文字は、コピーして貼り付ける）
- commit・push・マージ・デプロイは行っていません
