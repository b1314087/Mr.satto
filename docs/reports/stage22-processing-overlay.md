# 処理中の画面（画面全体を薄暗く・パネルの周りを光が周回）報告書

作成日：2026-11-01（利用者からの依頼「処理中の時に画面全体が薄暗くなって、真ん中に処理中のパネルのようなものがでて、そのパネルの周りを光が周回するようにして欲しい」による。範囲は「全ツールに入れる」を選択。ファイル名は既存の報告書と重ならないよう stage22 とした）

## 最初に（結論）

全ツール共通の「処理中」の表示を、次のように変えました。

- 処理している間、画面全体を薄暗くし、中央にパネル（回るマークと「処理中...」などの文字）を出す
- パネルの縁を、水色→紫→白の光が回り続ける（実行ボタンの光と同じ色・同じ仕組み）
- 処理中は、後ろの画面を操作できない（二重の実行や、処理中の設定の変更を防ぐ）。終わるとパネルは消え、これまでどおり完了のポップアップが出る
- 進み具合を測れている処理（動画・音声の％、PDF圧縮の「目標のサイズに合わせて調整しています…（3回目／最大6回）」）は、パネルに表示する
- 途中で止められる処理（動画・音声の各ツール、年度カレンダーの予定の読み込み）は、止めるボタンをパネルの中に移した
- 「動きを減らす」設定の人には、光とマークを回さず、縁に固定の光を出す
- commit・push・マージ・デプロイは行っていません

## 2. 仕組み

- 共通の表示部品 `src/components/common/processing-status.tsx`（88ツールが使用）の「処理中」を、画面全体を覆う表示（document.body に出す）に変えた
  - 文字の部分は role="status" のままで、読み上げソフトにも状態が伝わる
  - 中止できる処理は、`onCancel`（中止する関数）を渡すと、パネルに中止のボタンが出る
- 見た目は `src/app/globals.css` の `.ms-busy-overlay`・`.ms-busy-panel`・`.ms-busy-spinner`
  - 縁の光は、実行ボタンと同じ `--ms-busy-angle` の円すい状のグラデーションを、パネルの縁だけに見えるよう切り抜いて回す（1周1.6秒）
  - 背景は、半透明の濃い紺（rgb(6 12 26 / 0.55)）

### 見つけて直した不具合

「処理が速く終わっても、最低0.6秒は処理中の表示を続ける」仕組み（`src/lib/utils/busy-hold.ts`）が、処理を始めていない表示にまで効いていた。

- 年度カレンダーで予定のファイルを読み込むと、カレンダー本体の表示まで「処理中」になり、画面全体が薄暗いまま残って、ボタンが押せなくなっていた
- 以前は小さな文字が一瞬出るだけで、目立たなかった
- 0.6秒続けるのを、その表示自身が処理中になったときだけにした

## 4. 実行したテストと結果

新しいテスト（`tests/ui/processing-overlay.spec.ts`）：4件すべて合格

- 処理中は画面全体が薄暗くなり、パネルの縁の光が回り続ける。後ろの画面は押せない。終わると消える
- 動きを減らす設定では、光を回さない
- 年度カレンダーの予定の読み込みを、パネルの中止のボタンで止められる
- 予定の読み込みのあと、処理していない表示まで処理中の画面に残らず、そのまま操作できる（見つけた不具合の確認）

関係する既存のテスト：

- 1回目（共通部品・年度カレンダー・AI（年度カレンダー）・ツール間の受け渡しなど）：686件まで実行したところで、テスト用のサーバーが時間の上限で止まった。それまでの失敗は、見つけた不具合（処理中の画面が残る）によるものと、共通部品のきまりの確認（処理中の表示は共通のスピナーを使う）の1件。どちらも直した
- 2回目（共通部品 `tests/ui` 全体、全ツールのプレビュー `preview-all.spec.ts`、動画・音声・PDF圧縮・外字チェック）：380件合格、2件は条件付きで飛ばす既存のテスト（不合格なし）

型チェック（`tsc --noEmit`）・ESLint（`src` と `tests`）：エラー・警告なし。本番ビルド（`next build`）：成功。

全ツールに関わる変更のため、関係する範囲を広めに取りました（全件ではありません）。

## 5. 未対応事項・残っている制約

- 処理が速く終わる場合も、最低0.6秒は処理中の画面が出る（これまでの「処理中」の表示と同じ決まり）
- 処理中は、ページの他の部分（説明文やメニュー）も押せない。処理が長いツールでは、終わるまで待つ必要がある
- 実機（iPhone・Android・Safari）での見え方は確認していない（必須ではない）

## Claudeの意見

- すぐ終わる処理で、画面が一瞬暗くなるのが気になる場合は、「0.3秒以上かかったときだけ出す」ように調整できます。
- 今回、0.6秒の表示の続け方の不具合が見つかったのは、画面全体を覆う表示にしたことで目立つようになったためです。直したことで、他のツールでも関係のない表示が残ることはなくなりました。
