# PDF圧縮の目標サイズ（MB）指定 報告書

作成日：2026-11-01（利用者からの「PDF圧縮がわかりにくい。何MBにするかを数値で設定できるようにして欲しい」という依頼による。ファイル名は既存の報告書と重ならないよう stage20 とした）

## 最初に（結論）

PDF圧縮で、「何MB以下にするか」を数字で指定できるようにしました。これを初期の圧縮方法にしています。

- 画面の「圧縮のしかた」で、「サイズを指定する（おすすめ）」か「画質を指定する（詳しい設定）」を選びます。初期は「サイズを指定する」です
- 「何MB以下にしますか？」に数字を入れて「圧縮する」を押すと、そのサイズ以下になるまで、PDFの中の画像の画質と大きさを自動で下げます。目標以下になる中で、いちばん画質が良い設定を選びます
- PDFを選ぶと、元のサイズの半分が初期値として入ります。そのまま「圧縮する」を押すこともできます
- よく使うサイズ（1・2・3・5・10MB）のボタンがあり、元のPDFより小さいものだけを表示します
- 目標に届かないとき（文字が中心のPDF、JPEG以外の画像のPDFなど）は、そのことと理由、次にできること（PDF分割）を伝え、いちばん小さくできた結果をダウンロードできます
- 以前の画質の設定（プリセットと数値）は、「画質を指定する（詳しい設定）」にそのまま残しました
- 文字・図形・リンクは変えません。処理はブラウザの中だけで、ファイルを送信しません。広告・ダウンロードの制御は変えていません
- commit・push・マージ・デプロイは行っていません

## 2. 仕組み

`compressPdfToTarget`（`src/lib/processors/browser/pdf.ts`）：

1. まず、画像を変えずにPDFの内部構造だけを整理します。これで目標以下なら、画像の画質は下げません
2. 次に、いちばん小さくなる設定（画質20・長辺400px）で試します。それでも目標を超えるなら、これ以上は小さくできないため、いちばん小さい結果を「届かなかった」として返します
3. 目標以下になる設定の中で、いちばん画質が良いものを、14段階（画質85・長辺3000px 〜 画質20・長辺400px）から二分探索で探します

- 試す回数は最大6回です。画面に「目標のサイズに合わせて調整しています…（3回目／最大6回）」と表示します
- 使わなかった試行の結果は、その場でメモリから解放します
- 1MBは1,000,000バイトとして計算します。アップロードの上限が「1MB＝1,000,000バイト」の場合と「1,048,576バイト」の場合のどちらでも、確実に収まるようにするためです。サイズの表示も、目標と同じ単位（小数2けたのMB）にそろえました

### 入力の確認

- 空欄・数字以外・範囲外（0.05〜1000MB）は受け付けず、欄の下に直し方を表示し、「圧縮する」を押せなくします
- 全角の数字・小数点、「MB」の付いた入力（例：0.5MB）も受け付けます
- 元のPDFがすでに目標以下のときは、「すでに◯MB以下です」と伝えます
- とても小さいPDF（0.1MB以下）は、「すでに十分小さいため、サイズの指定では圧縮できません」と伝え、「画質を指定する」を案内します

## 3. 実測（写真2枚と文字の2ページのPDF、元のサイズ1.15MB）

- 目標0.5MB → 0.38MB（画質80・長辺2500px。目標以下で、いちばん画質が良い設定）
- 目標1MB → 0.5MBのときより大きく、画像を大きく残した結果（テストで確認）

## 6. 未対応事項・残っている制約

- 小さくできるのは、PDFの中のJPEG画像だけです。文字が中心のPDF、PNGなどJPEG以外の画像のPDFは、目標に届かないことがあります（そのことを画面で伝えます）
- 目標に合わせるため、最大6回圧縮をやり直します。画像の多い大きなPDFでは、時間がかかることがあります（途中経過を表示）
- ファイル一覧（共通部品）に出るサイズは、これまでどおり1MB＝1,048,576バイトの表示のため、「1.1 MB」と「1.15MB」のように少し違って見えることがあります。共通部品は他のツールにも使われているため、今回は変えていません

## Claudeの意見

- 「何％小さくする」ではなく「何MB以下」にしたのは、使う場面（メールの添付・アップロードの上限）がMBで決まっていることが多いためです。
- 1MBを1,000,000バイトで計算しているため、目標ぴったりより少しだけ小さくなります。上限に確実に収めることを優先しました。
- ファイル一覧のサイズ表示（1.1 MB）と目標の表示（1.15MB）の違いが気になる場合は、共通部品の表示をそろえる工程を別に設けることを提案します。
