# 書類番号の自動採番（日付＋通し番号／時刻）報告書

作成日：2026-11-01（利用者からの依頼「見積書、注文書、請求書の管理番号を日付と番号を組み合わせて簡単に作れるようにしたい」「末の三桁だけはプルダウンで選べるようにして欲しいけど、それか時刻をいれる方式」による。両方を切り替えて使える形で合意。ファイル名は既存の報告書と重ならないよう stage24 とした）

## 最初に（結論）

見積書・請求書・注文書・見積書／注文書の一体作成で、「自動採番」のボタンで入る書類番号を、次の形にしました。

- 形：「記号-発行日-末尾」。例：`INV-20261101-001`
  - 記号：見積書＝EST、請求書＝INV、注文書＝ORD（一体作成は見積書の EST）
  - 日付：入力した「発行日」から取る（以前はボタンを押した日だった）
- 末尾は、ボタンの下の切り替えで選ぶ
  - 通し番号：001〜050 のプルダウンで選ぶ。このブラウザで、同じ種類・同じ発行日に前回使った番号の次を、最初から選んでおく
  - 時刻（時分）：押した時刻を4桁で入れる（例：15時13分 → `1513`）
- 以前は末尾がでたらめな3桁だった
- 番号の欄は、これまでどおり手で書き換えられる
- commit・push・マージ・デプロイは行っていません

## 2. 仕組み

- 使った通し番号は、このブラウザの中（localStorage）に、「種類:日付 → 最後に使った番号」として覚える。サーバーには送らない
  - 見積書と請求書は別々に数える。同じ取引で、見積書・注文書・請求書の末尾をそろえやすい
  - プルダウンで前の番号を選び直しても、記録は大きい方を残す（次に出す番号が戻らない）
  - 記録は直近60件（種類・日付の組）だけ残す
  - 保存できない環境（シークレットウィンドウの一部など）でも、番号を入れることはできる
- 時刻を選んだときは、通し番号の記録は増やさない
- 欄の下に「この発行日の請求書は、このブラウザで 001 まで使いました。次の番号を選んでいます。」のような案内を出す

## 5. 残っている制約

- 通し番号の記録は、そのパソコン・そのブラウザだけ。別のパソコンやスマホ、閲覧履歴（サイトのデータ）を消したあとは、また 001 から選ばれる。番号は手で選び直せる
- プルダウンは 050 まで。それより先は番号の欄を直接書き換える
- 時刻方式は、同じ1分の間に同じ種類を2枚作ると同じ番号になる

## Claudeの意見

- 複数のパソコンで同じ番号の続きを使いたくなった場合は、ブラウザの中だけでは足りず、保存先（アカウントなど）が必要になります。そのときに改めて相談させてください。
