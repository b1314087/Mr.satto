## 最初に（結論）

見積書・請求書・注文書・見積書／注文書の一体作成に、「メモを貼り付けて、まとめて入力する」を追加しました（最初は閉じていて、開くと使える）。

- 「項目名：中身」を1行ずつ書いたメモを貼り付けて「メモから入力する」を押すと、各欄に入る
- 「記入例を入れる」で、書き方の見本が入る
- 読めなかった行は「2行目「色：青」：「色」という項目はありません」のように、行番号と理由を一覧で出す。読めた行だけ入れる
- メモに書いた項目だけを書き換える。明細を書いたときは、明細を書いた内容に置き換える
- AI・外部のサービスは使わない。メモはブラウザの中だけで読み取る
- commit・push・マージ・デプロイは行っていません

## 2. 書き方

| 項目名 | 入る欄 |
| --- | --- |
| 書類番号（番号・管理番号・見積番号・請求番号・注文番号） | 書類番号 |
| タイトル（書類タイトル・件名） | 書類タイトル |
| 発行日（日付） | 発行日 |
| 期限（有効期限・支払期限） | 見積書の有効期限・請求書の支払期限 |
| 納期 | 注文書の納期（日付）。一体作成では注文書の納期の欄（自由な文字） |
| 宛先（宛名・取引先・お客様） | 宛先の会社名 |
| 宛先担当・宛先郵便番号・宛先住所・宛先電話・宛先メール | 宛先の各欄 |
| 発行者（自社）、発行者担当・発行者住所 など | 発行者の各欄 |
| 明細（品目） | 明細。「品名, 数量, 単位, 単価」。「品名, 数量, 単価」「品名, 単価」も可（単位は「式」、数量は1） |
| 税率（消費税） | 10・8・0 |
| 端数（端数処理） | 切り捨て・四捨五入・切り上げ |
| 備考（メモ） | 備考（複数行は改行でつなぐ） |
| 銀行・支店・口座種別・口座番号・口座名義 | 振込先（請求書だけ） |

- 「：」は全角・半角どちらでもよい。全角の数字も読む
- 日付は「2026/11/01」「2026-11-1」「2026年11月1日」「2026.11.1」
- 金額の「¥」「円」「100,000」のカンマは読み飛ばす。明細の区切りは「,」「、」かタブ
- 空行と「#」で始まる行は読み飛ばす

## 4. 実行したテストと結果

- 基本の項目・宛先・発行者・明細（4つ・3つ・2つの形）・税率・端数・備考を読む

- 金額の桁区切りのカンマと区切りのカンマを見分ける。ありえない日付（2月30日）は読まない
- 請求書の振込先、注文書の納期、一体作成の納期。3種類の記入例が、そのまま全部読める

## 5. 残っている制約

- 決まった項目名しか読まない（言い回しの揺れは、上の表の別名の範囲だけ）
- 明細で、数量と単価を区切りの後に空白なしで続けると（「足場,2,150」）、「2,150」を金額の桁区切りと読むことがある。区切りの後に空白を入れるか、「品名, 数量, 単位, 単価」の4つで書けば問題ない
- 年のない日付（「11/30」）や和暦（「令和8年」）は読まない
