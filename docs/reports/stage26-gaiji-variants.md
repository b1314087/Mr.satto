# 外字・特殊文字チェック：使い方の枠を削除・形の違う字（異体字）を表示 報告書

作成日：2026-11-01（利用者からの依頼「使い方はいらんから消して」「高橋って打っても髙橋が出てこんのはおかしくない？高の外字は全て出てくる必要がある」による。ファイル名は既存の報告書と重ならないよう stage26 とした）

## 最初に（結論）

- 画面の上の「使い方」の枠を消した
- 入力した文字に、名前でよく使われる形違いの字（異体字）があれば、結果に「形の違う字（異体字）」として出すようにした
  - 例：「高橋」→ 高の形違い「髙」（U+9AD9・機種依存文字）、橋の形違い「槗」（U+69D7・Shift_JISにない）
  - それぞれの字に、コード、Shift_JISでの扱い、「〇をコピー」のボタンを付けた
  - 「髙橋」と入力したときは、これまでどおり髙を機種依存文字として見つけ、加えて形違いの「高」も出す
- 注意が必要な文字が無いときも、形の違う字はその下に出す
- commit・push・マージ・デプロイは行っていません

## 2. 形の違う字の一覧について

- `src/lib/gaiji/variants.ts` に、名前・地名でよく使われる形違いの字のまとまりを約90組入れた（高・髙、崎・﨑・嵜・碕、吉・𠮷、辺・邊・邉、斉・斎・齋・齊、沢・澤、浜・濱・濵、島・嶋・嶌、渡辺の辺、德・徳、鴎・鷗、𠮟・叱 など）
- どの字から引いても、同じまとまりの他の字が出る（高→髙、髙→高）
- 一覧の字は、貼り付けたときの文字の正規化（NFC）で別の字に変わらないものだけにした（互換漢字は入れていない）

### 「高の外字は全て」について

- 「髙」は、文字コード（Unicode）にある字のため、この一覧で出せる
- 会社や自治体が独自に作った外字（私用領域の文字）は、作った所ごとに中身が違うため、外から「高の外字」を知ることはできない（入力にあれば、これまでどおり「外字」として見つける）
- 同じ文字コードのまま形だけを変える「異体字セレクタ（IVS）」の字形（例：辻の点の数、邉の細かい形の違い）は、今回は出していない

新しく足したテスト：

## 5. 残っている制約

- 一覧にない字の形違いは出ない（必要な字があれば、一覧に足せる）
- 独自の外字・異体字セレクタの字形は出ない（上の2.）
