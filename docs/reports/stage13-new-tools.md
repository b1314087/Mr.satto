## 4. 実装したツール

### 4-1. 外字・特殊文字チェック

- 入力：貼り付けた文字、または `.txt` `.csv` `.tsv` `.md` `.docx` `.xlsx` `.pdf`（20MBまで、PDFは100ページまで）。文字コードは UTF-8、だめなら Shift_JIS として読みます。
- 検出する分類（重要度の高い順）：制御文字・置換文字・外字（私用領域）・異体字セレクタ・見えない文字・特殊な空白・結合文字（濁点の分離）・互換漢字・康熙部首・補助面の文字・絵文字・機種依存文字・Shift_JIS不一致・Shift_JISに保存できない文字・半角カナ。
- 結果：分類ごとに、文字・コード・名前・件数・場所の例（Wordは段落、Excelはシート名とセル番地、PDFはページ）・対処を表示。CSVでも保存できます（元の文章は含めません）。
- 整えたテキスト：置き換えても意味が変わらないものだけ（見えない文字の削除・特殊な空白・濁点の合成・互換文字・半角カナ・康熙部首）を直します。外字・互換漢字・補助面の文字・絵文字は、自動では変えません。
- できないことを画面に明記：外字の字形や意味は分かりません。実際にその環境で表示できるかは判定できません。「見つかりませんでした」は安全の保証ではありません。誤検出・検出漏れがありえます。Wordの記号用フォント（Symbol・Wingdings）の箇条書きは、外字として誤検出されます。画像のPDFやスキャンの文字は調べられません。古い形式（.doc・.xls）は、.docx・.xlsx に保存し直してもらう案内を出します。
- あえて作らなかったもの：読み・部首・画数から漢字を探す機能。漢字データを取り込む必要があり、権利と規模の面で見送りました。

### 4-2. シフト表作成

- 勤務区分：略称（3文字まで）・名前・勤務/休み・開始/終了・休憩・色。夜勤など日をまたぐ勤務に対応（終了が開始以前なら翌日）。初期値は 早・遅・日・休・有給。最大12区分。
- スタッフ：最大60人。1人ずつ、または貼り付けでまとめて追加。並べ替え・削除。
- 表の入力：区分を選んで、マスを押す、マウスでなぞる、キーボード（Enter・スペース）。曜日・祝日を指定した一括入力（入っているマスを変えない指定あり）。日曜・祝日は赤、土曜は青の見出し。
- 集計：スタッフごとの出勤日数・休日数・未入力・実働時間、日ごとの出勤人数。
- 目安との比較（警告。利用者が決めた目安との比較だけ）：連続勤務の日数、勤務間の休息時間（夜勤の翌日分を含む）、1日の必要人数、未入力の数。該当するマスに印が付きます。法令への適合は判定しません。
- 入力の不備の検出：略称の空・重複・長すぎ、時刻の形式、開始=終了、休憩が勤務時間以上、スタッフ名の空・重複、年月の範囲。不備があるうちは書き出しを止め、理由を表示します。
- 出力：PDF（A4横。30人を超えるとページ分割）・Excel（色つき。集計列と凡例シート）・CSV（UTF-8・BOM付き。数式として実行される名前には `'` を付ける）。保存ファイル（JSON）の作成と読み込み（形式・内容を検証）。
- 入力した名前や勤務は外部に送信されません（通信を記録するテストで確認）。

## 5. 見送った候補と理由

| 候補 | 理由 |
|---|---|
| Word結合、Word→画像 | 未実装。ただし、Word文書の再現（レイアウト・フォント）が必要で、ブラウザ内では品質の保証が難しい。今回の優先順（計画済み・重複なし・低コスト）で、上の2つより後になる。 |
| PDF比較 | 未実装。文字の差分と見た目の差分のどちらを目的にするかで作りが大きく変わり、仕様の確認が先に必要。 |
| 写真プリントサイズ変換 | `image-layout`（配置してPDF/画像に書き出し）・`image-passport-photo` と用途が近く、重複の整理が先に必要。 |
| 年齢・記念日計算 | `date-weekday-tool` の日付の加減算と近い。独立したツールにするほどの規模ではなく、既存ツールへの機能追加が適切。 |
| カラーコード変換 | `color-palette-generator` が近い領域。単独の価値が小さい。 |
| データ連携（ExcelとJSONの直接交換） | 指示書が「過去に不要と判断された」とした候補のため、復活させない。 |

## 10. 残っている課題

- 外字検出は、文字コードの範囲による判定です。実際の書類・名簿での検出漏れ・誤検出の確認は、未実施です。実際の書類で試して、誤検出が多い分類があれば教えてください（Word の箇条書きの記号用フォントは、すでに既知の誤検出です）。
- シフト表の実機（スマートフォン・タブレット）での操作感は、未確認です。なぞり入力はマウス向けで、タッチではマスを押して入力します。
- シフト表は、現在の年月を端末の日付から決めます（月の変わり目の直前にサーバー側と端末側で月がずれる場合、表示が一瞬ずれる可能性があります）。
- 休日・祝日は内蔵のカレンダーに基づきます。会社独自の休業日は、勤務区分「休み」で入れてください。
- 見送った候補（5.）は、必要になったときに別途判断してください。

## Claudeの意見

外字チェックは「安全だと保証しない」ことが一番大事なので、画面の説明とよくある質問に、できないことを先に書きました。シフト表は、自動で作る機能を求められがちですが、法令との適合まで責任を持てない以上、今回のように「入力・確認・書き出し」に絞るのが安全です。次に作るなら、見送った中ではPDF比較が使い道がはっきりしていますが、先に「何を比べたいか」を決める必要があります。
